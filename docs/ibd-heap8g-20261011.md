# Увеличение Java heap до 8 GiB

По просьбе пользователя параметры GPU-конфигурации изменены на
`-Xms4g -Xmx8g` в .run/BitcoinNodeApplication GPU.run.xml и в локальной
конфигурации IntelliJ. Окно 1024 и размеры кешей сохранены.
Предыдущий процесс штатно остановлен через Spring Boot Admin.

Первый запуск PID 34896 перешел в FAILED при синхронизации заголовков:
`IllegalStateException: Parent header is unknown: 00000021cce0cd4553ffc5545f38c6ec2696783f87a1252818f07c52bf9b362b`.
Это отдельная ошибка обработки заголовков, причина здесь не установлена;
исчерпания памяти не было. Процесс штатно остановлен и запущен повторно.

Работающий PID 27808: jcmd подтвердил InitialHeapSize=4294967296,
MaxHeapSize=8589934592. Повторный запуск успешно возобновил синхронизацию.
За первые 87,8 секунды RPC-замера высота 775265 -> 775289, 10 пиров;
в 09:29:31 лог показал высоту 775290 и около 0,4 блока/с.
Показания jstat: Full GC=0, суммарное время GC около 0,588 с.
Heap использует примерно 2,53 GiB, доступно системе около 9,7 GiB RAM.
Буфер в этот момент заполнен лишь до 388 блоков, кеш UTXO прогревается:
замер не доказывает устойчивость при полностью заполненном окне и не позволяет
приписать изменение скорости только увеличению памяти.

Данные: target/ibd-heap8g-retry-20261011.jsonl.
Диагностика: target/mainnet-gc-27808.log и target/mainnet-node.log.
Нода оставлена запущенной.
