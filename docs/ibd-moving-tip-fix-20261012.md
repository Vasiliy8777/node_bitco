# Остановка на завершении IBD: 12 октября 2026

## Причина

В 01:33:24 PID 39980 перешел из SYNCHRONIZING_BLOCKS в FAILED:

```
Initial block synchronization ended before active tip reached best header tip:
activeHeight=970861, bestHeaderHeight=970966
```

Стек: NodeLifecycleService.verifySynchronized:693 -> start:344 ->
NodeLifecycleRunner.run:83. BlockSyncCoordinator планирует одну загрузку
относительно снимка лучшего заголовка на старте. Первоначальная цель 970861
была достигнута, но заголовки за время продолжительной IBD продвинулись на
105 блоков. Lifecycle ошибочно считал это повреждением состояния и завершал
синхронизацию с FAILED вместо нового раунда загрузки. Реконнекты пиров рядом
с ошибкой не являются причиной данного исключения. После FAILED процесс
оставался жив, GPU ждала синхронизированную работу.

## Исправление

NodeLifecycleService.synchronizeBlocks теперь повторяет загрузку и проверку
актуального tip до совпадения активной цепочки с лучшим заголовком. Отмена
проверяется перед и после каждого раунда. При неподвижной цели и отсутствии
прогресса сохраняется явная ошибка вместо бесконечного цикла. Проверка
minimumChainWork сохранена. После успешного завершения обновления принимает
LiveChainSynchronizer, как и раньше.

В application-mainnet.yml уточнены комментарии о native cache и prefetch.
Параметры heap, кешей, окна и размещения базы не менялись: heap 8 GiB,
окно 1024, chainstate на SSD, блоки и undo на HDD.

## Проверка

Новый NodeLifecycleCatchUpTest воспроизводит два продвижения заголовков во
время загрузки. До исправления: один раунд, активная высота 105 при цели 106;
тест падает. После исправления: три раунда, активная высота и цель 107.
Дополнительно проверены отсутствие прогресса при неподвижной цели и отказ
при работе цепочки ниже minimumChainWork.

45 тестов прошли, включая существующие проверки IBD, перехода RUNNING,
переподключения и штатной остановки. git diff --check пройден.
