# Постоянный индекс основного mempool

Mempool теперь хранит отдельный индекс parent/child-связей и связных компонент.
Обычный приём объединяет только соседние компоненты, удаление разбивает только
затронутые. Индекс хранит txid, не объекты транзакций или UTXO. Обнаружение
существующих детей при добавлении родителя поддерживает обратный порядок
появления зависимостей. Удаление потомков использует индекс вместо обхода
входов всех транзакций пула.

Версия графа меняется при структурных изменениях и изменении modified fee.
Повторное чтение mining snapshot или fee diagram при неизменной версии
использует сохранённые chunk без повторного обхода inputs или проверки всех
комиссий. Полный кеш ограничен 65 536 транзакциями; для большего пула сохраняется
прежний ограниченный покластерный кеш. Ссылка на карту пула слабая, а результаты
содержат только метаданные. Версия отдельна от внешнего transaction-set sequence:
prioritisetransaction меняет комиссии, не состав пула.
