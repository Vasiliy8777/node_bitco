# Выполнение RPC-совместимости с Core 32.1

Инвентарь имён и реализация методов не доказывают полного совпадения схем,
параметров, ошибок и побочных эффектов. Подмена отсутствующих методов
заглушками не считается завершением.

| Область | Состояние |
| --- | --- |
| Каталог методов | Из 176 эталонных имён реализованы 55; отсутствует 121 имя. Добавлены три chain-wait RPC; полный список в [инвентаре](core32-rpc-method-inventory.md). |
| Схемы и help | Полные OpenRPC-записи/help chain-wait методов сравниваются с Core. Для остальных методов схемы остаются неполными. |
| Причины и детали ошибок | Для chain-wait сравниваются типы, позиции аргументов, диапазоны, hash, arity, named/positional conflicts и приоритеты. Для всего RPC полная матрица ещё открыта. |
| Реальное ожидание цепочки | Добавлены timeout/current_tip, уведомления активной цепочки, reorg и shutdown; [проверки](rpc-chain-wait-core32.md). |
| Остальные node RPC | Blockchain, control, network, raw transaction, util, hidden/regtest и ZMQ методы инвентаря ещё требуют реализации/сопоставления. |
| Кошелёк и signer | В полном инвентаре есть 58 отсутствующих wallet-методов и enumeratesigners. Объём полноценного кошелька уточняется отдельно; эти имена не исключены из общего счётчика. |
| Transport/dispatch | Требуется полное сравнение HTTP/JSON-RPC, named args/aliases, batch, notifications, warmup, lifecycle и ограничений ресурса. |

Mempool/приём пакетов тоже ещё не полностью закрыт:
[актуальный статус](mempool-core32-execution.md).
