# Запросы графа и замыкания конфликтов через постоянный индекс

Ancestors/descendants, graphView, ancestorQuery/descendantQuery и cluster теперь
берут связи из MempoolGraphIndex. Для поиска родителей, детей и компоненты не
строится новый граф по inputs всего пула. Линейзатор по-прежнему читает inputs
запрошенной компоненты; независимые компоненты для этих запросов не обходятся.

graphViews/detailedSnapshot используют локальную карту txid → chunk на время
одного атомарного запроса. Первая запрошенная запись компоненты запускает её
линейзацию; остальные используют тот же результат. Между запросами эта карта
не сохраняется и объекты транзакций дополнительно не удерживает.

Индивидуальный и пакетный admission также используют индексированное замыкание
потомков конфликтов. Multi-root обход включает существующие корни, объединяет
пересекающиеся подграфы без повторов и не создаёт вершины для неизвестных txid.
Все реальные конфликтующие txid взяты из spent-index действующего пула.
Расчёт prospective-графа и остальные policy/RBF-проверки сохранены.
